# Storeup Page Design

**目标**

将前台收藏页 `/index/storeup` 重构为与 `demo/user_favorite/code.html`
风格一致的影院感收藏列表页，同时保留现有搜索、分页、点击卡片跳详情
逻辑，并在不新增后端接口的前提下补充真实可用的取消收藏与有限排序。

**设计结论**

- 页面采用“左侧固定侧栏 + 右侧收藏网格内容区”的结构。
- 主内容区包含：标题区、搜索与排序工具区、收藏卡片网格、分页区。
- 卡片点击继续进入详情页；卡片右上角收藏按钮改为真实可用的取消收藏。
- 排序仅接入现有接口可支持的排序字段，不做伪交互。
- 原型中的下载、设置、悬浮新增按钮、多内容类型筛选不做强行落地。

**页面结构**

- 左侧固定侧栏
  - 品牌区
  - Home
  - Discover
  - My List 当前高亮
  - 返回个人中心
  - 退出登录
- 右侧内容区
  - 小标题 `Personal Collection`
  - 大标题 `My List`
  - 搜索框
  - 排序按钮组
  - 收藏卡片网格
  - 分页区
  - 空态区

**数据与交互**

- 收藏列表继续调用 `storeup/list`
- 搜索继续使用 `name like`
- 分页继续复用现有分页参数
- 排序接入现有 `sort/order`
  - 默认 `addtime desc`
  - 可补充 `name asc`
- 取消收藏使用现有 `storeup/delete`
- 点击卡片继续跳 `/index/${tablename}Detail?id=${refid}&storeupType=1`

**无法原样实现的原型功能**

- `Movies / Series / Watchlist` 多分类筛选：
  当前收藏数据没有对应的完整分类体系支撑，只保留单一收藏视图。
- `Downloads`：
  当前无对应页面与业务逻辑。
- `Settings`：
  当前无独立设置中心，避免做伪入口。
- 右下角悬浮 `add`：
  收藏新增发生在详情页，不在收藏页直接创建。

**视觉要求**

- 深蓝黑影院背景
- 左侧固定导航
- 右侧沉浸式头部与卡片网格
- 海报卡片 hover 放大、阴影增强
- 金色激活态与按钮
- 搜索框、排序控件和分页统一影院风格
- 移动端降级为顶部导航 + 单列/双列卡片

**风险控制**

- 以 `storeup/list.vue` 为主文件完成重构
- 新增一个小 helper 文件承载图片解析和排序配置，便于测试
- 不新增后端接口、不新增表字段
