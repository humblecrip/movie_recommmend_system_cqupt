# Center Page Design

**目标**

将前台个人中心路由 `/index/center` 重做为与 `demo/user_detail/code.html`
一致的影院感编辑页，同时保留现有资料编辑、头像上传、修改密码、
收藏跳转、后台菜单跳转和退出登录逻辑，不新增后端接口。

**设计结论**

- 页面采用“左侧固定导航 + 右侧沉浸式内容画布”的结构。
- 默认主舞台为“个人中心”资料编辑卡片，布局和视觉语言对齐原型。
- “修改密码”“我的收藏”以及后台菜单入口仍复用现有 tab/路由能力，
  但外观统一收敛到新侧栏导航，不再保留旧的 Element 左侧标签页样式。
- 资料提交、密码修改、头像上传、敏感词读取、`sessionForm` 本地缓存
  与后端更新接口全部沿用现有逻辑。

**页面结构**

- 左侧固定侧栏
  - 品牌区
  - 个人中心主入口
  - 修改密码入口
  - 后台功能入口列表
  - 我的收藏入口
  - 退出登录入口
- 右侧内容区
  - 顶部氛围背景
  - 页面标题与副标题
  - 玻璃卡片式主内容面板
  - 根据当前面板展示资料编辑或密码修改表单

**数据与交互**

- 资料编辑继续使用 `sessionForm`
- 密码修改继续使用 `passwordForm`
- 头像展示优先使用当前 `sessionForm.touxiang`，无值回退默认头像
- 头像上传仍使用现有 `file-upload`
- 点击“确定”继续调用 `${userTableName}/update`
- 修改密码沿用原有校验：
  - 原密码正确
  - 新旧密码不同
  - 两次输入一致
- 点击“我的收藏”仍跳转 `/index/storeup`
- 点击后台菜单仍跳转 `/index/${table}?centerType=1`

**视觉要求**

- 深蓝黑背景、金色高亮、玻璃感卡片、柔和阴影
- 表单双列布局，对齐原型字段排布
- 头像区改为大圆形头像与悬浮上传按钮
- 按钮保留原型中的金色主按钮与描边次按钮
- 移动端降级为单列布局，侧栏改为横向滚动或顶部区块

**风险控制**

- 尽量只修改 `center.vue`
- 新增一个小型辅助模块用于导航项与头像地址解析，便于测试
- 不改后端接口，不新增持久化字段
